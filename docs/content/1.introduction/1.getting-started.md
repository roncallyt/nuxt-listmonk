# Getting Started

## Installation

1. Add nuxt-listmonk module to your nuxt.js project:

```bash [npx]
npx nuxi module add nuxt-listmonk
```

2. If necessary, add `nuxt-listmonk` to the `modules` key on `nuxt.config.ts` file:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-listmonk'],
});
```

## Usage

1. Set up your environment variables:

```text
NUXT_LISTMONK_HOST=""
NUXT_LISTMONK_LIST_ID=""
NUXT_LISTMONK_API_USERNAME=""
NUXT_LISTMONK_API_TOKEN=""
```

`NUXT_LISTMONK_LIST_ID` must be the positive numeric ID used by the authenticated
Listmonk API. Public list UUIDs previously submitted as the `l` form field are not
accepted.

Create a dedicated Listmonk API user with permission to create and query
subscribers and manage subscriptions for the configured list. Keep its access
token server-side; none of these values belong in `runtimeConfig.public`.

2. Add these options to the `listmonk` key on `nuxt.config.ts` file:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-listmonk'],
  listmonk: {
    host: process.env.NUXT_LISTMONK_HOST,
    listId: process.env.NUXT_LISTMONK_LIST_ID,
    apiUsername: process.env.NUXT_LISTMONK_API_USERNAME,
    apiToken: process.env.NUXT_LISTMONK_API_TOKEN,
  },
});
```

Subscriptions made by the module are confirmed immediately. When the e-mail
already exists, the configured list is added without changing the subscriber's
name, account status, attributes, or other list memberships.
